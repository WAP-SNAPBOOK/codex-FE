# SnapBook

> **예약과 문의를 채팅에서 한 번에!**  
> 네이버 예약·카톡으로 흩어져 있던 예약과 문의를, 한 곳의 채팅방에서 관리할 수 있게 해주는 서비스입니다.

---

## 📌 서비스 개요

SnapBook은 네이버 예약, 카카오톡 등 흩어져 있던 예약 과정을
하나의 채팅 흐름으로 통합하는 예약 관리 서비스입니다.
고객은 매장 전용 링크로 진입해 카카오 로그인 후 채팅방에서 바로 문의를 남기고,
날짜·시간·메뉴를 선택한 뒤 참고 이미지와 요청사항까지 한 번에 전달할 수 있습니다.

점주는 가입 과정에서 매장 기본 정보, 운영 시간, 휴무일, 메뉴와 옵션을 설정하고,
이후 들어오는 예약 요청을 채팅방과 예약 내역 화면에서 함께 관리할 수 있습니다.
예약 확정, 거절, 전달 사항 입력 결과는 메시지 카드 형태로 고객에게 반영되어
별도 연락을 반복하지 않아도 예약 상태를 명확하게 공유할 수 있습니다.

SnapBook의 핵심은 예약, 상담, 사진 공유, 상태 안내가 서로 분리되지 않는다는 점입니다.
고객은 예약 맥락을 잃지 않고 소통할 수 있고,
점주는 여러 채널을 오가며 정보를 정리하지 않아도 되어 누락과 혼선을 줄일 수 있습니다.

## 🧩 핵심 기능

1. **매장 예약 링크 접속**
   - 인스타그램 프로필 링크 **SnapBook 예약 링크**를 클릭해 진입합니다.

2. **채팅방 접속**
   - 매장별 전용 **채팅방**이 생성되어, 고객은 일반 메신저처럼 메시지를 남길 수 있습니다.

3. **채팅방에서 바로 예약**
   - 채팅방 안에서 바로 **예약 폼**을 작성하여 예약을 접수합니다.
   - 날짜/시간/메뉴 선택과 함께,  
     원하는 스타일 사진을 **이미지 업로드**로 간편하게 전송할 수 있습니다.

4. **예약 확인 메시지**
   - 사장님이 예약을 **확정 / 거절**하면,
   - 그 결과가 **예약 상태 메시지 카드**로 채팅방에 표시되어  
     고객이 예약 현황을 한눈에 확인할 수 있습니다.

---

## 💡 SnapBook이 제공하는 가치

- ✅ **고객**
  - 채팅·예약·사진 전송을 한 번에 해결
  - 예약 내역을 채팅방에서 바로 확인
- ✅ **매장 사장님**
  - 예약/문의 기록이 한 채널로 모여 관리가 쉬움
  - 예약 상태(접수·확정·취소)를 메시지 형태로 고객에게 명확하게 전달
